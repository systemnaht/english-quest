# English Quest

Kleiner Englischtrainer für Anfänger mit:
- Hörtraining / Aussprache
- Deutsch + Russisch
- Gaming- und Creator-Wortschatz
- Satzbau mit Hilfe-Button
- XP / Level / Streak
- Daily Quest
- Boss Battle

## Inhalte aktualisieren
Die Lerninhalte liegen in `data.js`.
Wenn neue Schulvokabeln dazukommen, genügt in der Regel eine Aktualisierung dieser Datei.
