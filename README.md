# English Quest

Kleiner Englischtrainer für Anfänger mit:
- Hörtraining / Aussprache
- Deutsch + Russisch
- Gaming- und Creator-Wortschatz
- Satzbau mit Hilfe-Button
- XP / Level / Streak
- Daily Quest
- Boss Battle

## Inhalte aktualisieren
Die Lerninhalte liegen in `data.js`.
Wenn neue Schulvokabeln dazukommen, genügt in der Regel eine Aktualisierung dieser Datei.
Neue Wörter werden als Einträge in `VOCAB_BANK.school` ergänzt und stehen dadurch automatisch
im Wörter-Quiz, in der Daily Quest und im Boss Battle zur Verfügung.
Weitere Wortkategorien können über `VOCAB_CATEGORIES` und `VOCAB_BANK` ebenfalls in `data.js`
konfiguriert werden.
